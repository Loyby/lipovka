# Липовка на iPhone

Та же игра, что и на Android: общий код (игра, данные, все экраны и пиксель-арт) лежит в модуле `shared`
(Kotlin Multiplatform + Compose Multiplatform), а iPhone-приложение в `iosApp/` только показывает его.

## Чем iPhone-версия отличается

- **Шаги** считает сам iPhone (Core Motion, «Движение и фитнес»), а Apple Watch добавляет свои. Фоновая служба не нужна:
  iPhone всё время считает сам и помнит неделю, а Липовка забирает шаги, когда её открывают.
  Пока приложение открыто, сумка двигается каждые несколько секунд.
- **Уведомления**: одно утреннее, в 9:00, если они включены в настройках.
- **Виджета** пока нет (на iPhone его нужно писать отдельно, на Swift).
- **Health Connect** есть только на Android. На iPhone вместо него Core Motion.
- **Резервная копия** сохраняется через приложение «Файлы», и её можно перенести с Android и обратно.
- **Язык** переключается в настройках Липовки сразу, без перезапуска.

## Как получить Lipovka.ipa

Mac не нужен: приложение собирает бесплатный macOS-сервер GitHub Actions (`.github/workflows/ios.yml`).

1. Откройте вкладку **Actions** репозитория, выберите workflow **iOS** и последний зелёный запуск
   (или нажмите **Run workflow**, чтобы собрать заново).
2. Внизу страницы запуска, в разделе **Artifacts**, скачайте **Lipovka-ipa-…** (любой из них, если их несколько: это одна и та же сборка на разных Mac). Это zip-архив, внутри лежит `Lipovka.ipa`.

Этот .ipa не подписан. Подписывает его ваш Apple ID при установке.

## Как установить на iPhone с Windows (бесплатный Apple ID)

Понадобится Windows-компьютер, кабель для iPhone и ваш Apple ID.

1. Установите **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store): https://www.apple.com/itunes/ и
   https://support.apple.com/en-us/103232. Sideloadly нужны их драйверы.
2. Установите **Sideloadly**: https://sideloadly.io
3. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
4. Запустите Sideloadly, перетащите в него `Lipovka.ipa`, введите свой Apple ID и нажмите **Start**.
   Пароль уходит только в Apple. Если боитесь за основной аккаунт, заведите отдельный бесплатный Apple ID.
5. На iPhone откройте **Настройки → Основные → VPN и управление устройством**, выберите свой Apple ID и
   нажмите **Доверять**.
6. На iOS 16 и новее включите **Режим разработчика**: **Настройки → Конфиденциальность и безопасность →
   Режим разработчика**. iPhone перезагрузится.
7. Откройте Липовку и разрешите «Движение и фитнес».

### Ограничения бесплатного Apple ID

- Подпись живёт **7 дней**. Потом приложение перестаёт открываться, хотя данные сохраняются.
  Чтобы продлить, снова установите тот же .ipa через Sideloadly (шаг 4). Письма, марки и шаги никуда не денутся.
  В Sideloadly есть автообновление подписи, если компьютер включён и iPhone в той же Wi-Fi сети.
  Альтернатива: **AltStore** (https://altstore.io) с AltServer для Windows, он продлевает сам.
- Одновременно можно держать не больше **3** таких приложений.
- Перед переустановкой на всякий случай сохраните резервную копию: **Настройки → Резервная копия**.

### С платным аккаунтом разработчика ($99 в год)

Подпись живёт год, ставить можно через TestFlight без компьютера, а при желании выложить в App Store.
Для этого в GitHub Actions понадобятся сертификат и профиль из аккаунта. Сборку можно доработать под это.

## Сборка на Mac (если он появится)

```bash
brew install xcodegen
cd iosApp && xcodegen generate && open Lipovka.xcodeproj
```

В Xcode выберите свою команду (Signing & Capabilities) и запустите на подключённом iPhone.
